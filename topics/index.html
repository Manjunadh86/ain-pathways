  • What Are AI Agents? (Agents vs Workflows)

    An AI agent is a system in which a large language model uses tools in a loop to reach a goal, choosing each next step itself from the results of the steps before. A workflow also combines model calls and tools, but a developer fixes the steps and their order in code.

  • The Agent Loop (ReAct)

    The agent loop is the control code that runs an AI agent. It repeatedly shows a language model the task and everything observed so far, carries out the action the model chooses, feeds the result back, and stops when the model gives a final answer or a limit is reached. ReAct is the pattern in which the model interleaves written reasoning with those actions.

    IntermediateAbout 1 hAI EngineeringAI Agents and Agentic AIForward Deployed Engineer

  • Designing Tools for Agents

    Designing tools for agents is the work of deciding which actions an agent can take and how each one is presented to the model: its name, its description, its parameters, and what it returns on success and on failure. The model reads all of these as text, so they act as prompts.

  • Agent Memory

    Agent memory is everything an agent's program stores and later puts back into the model's context, so that the model can use information from earlier steps, earlier conversations or earlier corrections. Short-term memory is the message history of one conversation thread. Long-term memory is information saved outside the thread and reused in later ones.

  • Agentic RAG

    Agentic RAG is retrieval-augmented generation in which a language model controls retrieval instead of receiving search results once. Search is a tool the model may call, so the model decides whether to retrieve, what to ask for, whether the results are good enough, and whether to search again before it answers.

  • Planning and Task Decomposition

    Planning is the step in which an agent writes out the subtasks a goal requires, and their order, before or while it acts. Task decomposition is the splitting itself: turning one large request into smaller tasks, each of which can be run, checked and retried separately.

  • Prompt Chaining

    Prompt chaining is a workflow in which your code splits a task into a fixed sequence of language-model calls and passes the output of each call to the next one. Between calls, ordinary code can check the intermediate result, a check known as a gate, and decide whether to continue, retry or stop.

  • Routing

    Routing is a workflow pattern in which a first step classifies each input and then sends it down one of several predefined paths, each with its own specialised prompt, model or set of tools. The classifying step, called the router, can be a rule, a trained classifier or a language model.

  • Parallelization (Sectioning and Voting)

    Parallelization is a workflow pattern in which your code sends several LLM calls at the same time and combines their outputs with a fixed rule. In sectioning, each call handles a different, independent part of the task. In voting, the same task is run several times and the answers are counted or compared.

  • What Is Machine Learning?

    Machine learning (ML) is a way of building software in which the rule that turns inputs into outputs is worked out from example data by an algorithm instead of being written by a programmer. The learned rule, called a model, is then used to make predictions on data it has not seen before.

    BeginnerAbout 1 h 40 minMachine Learning

  • Linear Algebra for ML

    Linear algebra is the mathematics of vectors and matrices: ordered lists and rectangular grids of numbers, together with the rules for adding, scaling and multiplying them. Machine learning stores data and model parameters in these objects, so that one matrix operation does the work of thousands of separate multiplications and additions.

    BeginnerAbout 1 h 20 minMachine Learning

  • Calculus for ML (Derivatives and Gradients)

    A derivative measures how fast a function's output changes when one of its inputs is nudged. A gradient collects one such derivative for every parameter of a model, and training uses it to decide how to change each parameter so that the loss goes down.

    BeginnerAbout 1 h 40 minMachine Learning

  • Probability for ML

    Probability is the mathematics of uncertainty. It gives every possible outcome a number between 0 and 1 and supplies rules for combining those numbers. Machine learning uses it to describe noisy data, to say how confident a prediction is, and to update that confidence when new evidence arrives.

    BeginnerAbout 1 h 25 minMachine Learning

  • Statistics for ML

    Statistics is the set of methods for summarising data and for judging how far a number measured on a sample can be trusted for the wider population the sample came from. In machine learning it supplies the summaries, error bars and tests used to decide whether a measured difference between models is real or only noise.

    BeginnerAbout 1 h 30 minMachine Learning

  • The Python Data Stack (NumPy, pandas, scikit-learn)

    The Python data stack is a group of libraries that share one way of holding data. NumPy stores numbers in typed arrays and computes on whole arrays at once, pandas adds labelled tables called DataFrames, Matplotlib and Seaborn draw charts from them, and scikit-learn trains models through the same few methods: fit, transform and predict.

    BeginnerAbout 1 h 40 minMachine Learning

  • Data Collection and Cleaning

    Data collection is gathering the raw records a model will learn from, out of files, databases and web APIs. Data cleaning is finding what is wrong with those records (missing values, duplicates, wrong types, suspicious extremes), fixing or flagging each problem, and writing down every decision.

    BeginnerAbout 1 h 40 minMachine Learning

  • Exploratory Data Analysis

    Exploratory data analysis (EDA) is the habit of summarising and plotting a dataset before you model it. You compute a few statistics for every column, draw its distribution and its relationships with other columns, and use what you see to find data problems and to decide which models and features are worth trying.
