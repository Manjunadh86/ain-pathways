Machine Learning

A complete path through classical machine learning and deep learning. You start with the small amount of linear algebra, calculus and statistics that models rely on, learn to prepare data, then work through the main supervised and unsupervised algorithms, how to evaluate them honestly, neural networks, and finally how models are deployed and monitored.

Starts at beginner level54 topics3 shared with other paths7 stages

54 topics
Start this path: What Is Machine Learning?

Who it is for

Developers and analysts who can write basic Python and want to build and ship predictive models.

Before you start

  • Basic Python (functions, loops, lists and dictionaries).
  • School-level algebra. The math stage rebuilds everything else you need.

What you will be able to do

  • Prepare a raw dataset and explain every cleaning and feature decision.
  • Choose, train and tune a suitable model for a regression, classification or clustering problem.
  • Evaluate a model with the right metric and a split that does not leak information.
  • Explain how neural networks learn, and when a CNN, an RNN or a transformer fits.
  • Package, deploy and monitor a model, and know when it needs retraining.

Skills covered
