AASkill path · AI Agent Developer

AI Agents and Agentic AI

Learn what an agent is and when a simpler workflow is the better choice, then the building blocks (the loop, tools, memory, planning), the workflow patterns behind most production systems, the major frameworks and SDKs, and the open protocols that let agents reach tools, user interfaces and each other.

Starts at intermediate level45 topics11 shared with other paths5 stages

45 topics
Start this path: How Large Language Models Work

Who it is for

Developers who can already call an LLM API and want to build tool-using agents.

Before you start

  • You can call a chat model API and parse its response.
  • Basic Python. Most framework examples are in Python.
  • The first stage reviews the LLM essentials this path depends on.

What you will be able to do

  • Decide whether a problem needs a single call, a fixed workflow or an autonomous agent.
  • Implement the agent loop by hand, with sensible tools, memory and stopping rules.
  • Apply chaining, routing, parallelization, orchestrator-workers and evaluator-optimizer patterns.
  • Build the same agent in at least two frameworks and compare the tradeoffs.
  • Expose tools through an MCP server and explain where A2A, AG-UI, A2UI and Agent Skills fit.

Skills covered

Agent designWorkflow patternsAgent frameworksMCPAgent protocols
