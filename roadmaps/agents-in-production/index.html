Agents in Production

A working agent on your laptop is the start. This path covers where agents run (visual builders, hosted demos and the managed platforms from AWS, Google, Microsoft and OpenAI), how to see what they are doing with tracing tools, how to evaluate and test them, and how to keep them safe and affordable.

Starts at intermediate level27 topics9 shared with other paths5 stagesAbout 34 h 15 min of lessons (estimate)

27 topics
Start this path: Agent Deployment Architecture

Who it is for

Developers who have built an agent and now need to ship and operate it.

Before you start

  • You have worked through AI Agents and Agentic AI, or already understand the agent loop, tool design and MCP.
  • Basic familiarity with deploying a web service helps for the cloud platform topics.

This path builds on AI Agents and Agentic AI.

What you will be able to do

  • Choose a deployment target and explain what the runtime must provide.
  • Build and expose an agent with a visual builder and with a managed cloud platform.
  • Instrument an agent with traces and read them to diagnose a failure.
  • Build an evaluation suite covering final answers and tool-use trajectories.
  • Add guardrails, human approval and cost controls before launch.
