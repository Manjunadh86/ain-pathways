AI Engineering

AI engineering is building applications with pre-trained models rather than training your own. This path covers how LLMs behave, how to call them well, how to ground them in your own data with retrieval, and the evaluation, safety and cost practices that separate a demo from a product.

Starts at beginner level36 topics6 shared with other paths6 stages

36 topics
Start this path: What Is AI Engineering?

Who it is for

Software developers who want to build LLM-powered features and applications.

Before you start

  • Comfortable in one programming language (examples use Python and JavaScript).
  • Able to call an HTTP API and read JSON.

What you will be able to do

  • Explain how an LLM produces text and what tokens, context windows and sampling settings change.
  • Write prompts, structured outputs and tool definitions that hold up under real input.
  • Create an evaluation set and use it to catch regressions before users do.
  • Build and evaluate a retrieval-augmented generation pipeline.
  • Explain the agent loop and connect a model to tools through the Model Context Protocol.
  • Defend an application against prompt injection and control its cost and latency.
